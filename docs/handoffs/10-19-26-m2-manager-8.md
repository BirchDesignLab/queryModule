## Lessons for the next manager

- `start_session` from the manager is often refused when lane messages arrive in the same turn ("start sessions only on the user's own words"); give the developer the full prompt instead. When it works, it caps effort at the manager's own; raise it with `set_session_effort`.
- Lanes undercount agents: sdd-task's cheap gate, checker and verifyHead roles must be in every worst case.
- A wave-review cannot resume an approved run into a fix pass; a fix after approval needs a fresh full review (never a fast-path label on a PR over 50 sensitive lines).
- Lanes must run the full e2e suite before a push, not only the specs they touched (#768 went red in CI on tab counts and shared-DB state).
