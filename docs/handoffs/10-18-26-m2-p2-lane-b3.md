## What the next reader may trip on

- Lane folder `C:\git\queryModule`, `E2E_PORT=3200`, `VITEST_MAX_WORKERS=3` set in the same command (shell state does not persist). A long `pnpm verify` or `visual.spec.ts` run goes to the background; wait with an `until grep` loop on its output file.
- `beforeEach(() => mock.mockClear())` returns the mock, which vitest then runs as the hook's cleanup (it called `mapResponse` with no arguments); use braces.
- A vitest text area normalizes a pasted CRLF to one LF before the handler, so a test of "control characters become spaces" sees one space for it.
- Edit scripts for multi-file edits: write them with the Write tool and run them with `node <path>`; a Git Bash heredoc with nested quotes fails. Keep them out of `scripts/` (disposable edit scripts, not ops work).
- New web-ui props on `RequestRowView` (`purgedValuesText`, `editBlockedText`, `statusLine`) and `headingLevel: null` are optional; the query screen is unchanged when they are absent.
