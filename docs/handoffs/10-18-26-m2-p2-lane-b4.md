## What the next reader may trip on

- Lane folder `C:\git\queryModule`, `E2E_PORT=3200`, `VITEST_MAX_WORKERS=3` set in the same command (shell state does not persist). A full `pnpm e2e` takes about 15 minutes: run it in the background and read the output file.
- Run one e2e file as `pnpm e2e <file> --project=chromium`, never `pnpm e2e -- <file>`. The e2e database is fresh per `pnpm e2e` run (a `mkdtemp` data dir), shared by every spec in it: specs that count rows or Tab through the page opt in to `emptyQueryList`.
- A CSS comment with `#` and three or more hex digits (an issue number such as #767) trips the token-only rule in `shell.css.test.ts`: leave issue numbers out of `shell.css` comments.
- Biome's import-name sort flags a mixed `type` and value import list; run `pnpm exec biome check --write <paths>` before `pnpm verify`.
- The server closes a feed socket at 120 client frames a minute (4029); keep e2e frame counts low.
