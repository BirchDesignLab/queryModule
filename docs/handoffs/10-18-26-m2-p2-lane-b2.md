## What the next reader may trip on

- Lane folder `C:\git\queryModule`, `E2E_PORT=3200`, `VITEST_MAX_WORKERS=3` set in the same command (shell state does not persist). Run `visual.spec.ts` in full after any `shell.css` change (the admin rail and the `layout.*` constants are tested there).
- Windows quirks met: a Git Bash heredoc or a long `node -e '...'` with nested quotes fails or hangs, so write edit scripts with the Write tool and run them with `node <path>`; one-off edit scripts belong in the scratchpad, never under `scripts/ops/` (gate tier). Biome's `noDescendingSpecificity` flags unrelated `th`, `td`, `dt` and `dd` rules across `shell.css`, so new rules use class selectors.
- `AuditLog.tsx` and `AdminRequestView.tsx` guard their fetch with a ref key because each GET writes an audit row and StrictMode runs effects twice; keep that when changing the effects.
- A new `scripts/` folder must be named in `docs/architecture.md` (the docs-structure test fails otherwise).
