## Global Constraints

- TypeScript strict; no `any`. Every user-facing string is a message key in `packages/config/locales/en.json` (NFR-001), with the locale-keys test. American English in copy.
- Payloads, typed values and audit rows are regulated data on the client (spec 6.7): memory only; cleared on logout, 401 or user change; never in logs, analytics or URLs.
- Announcements polite and coalesced (spec 6.6); focus never moves on its own when a result arrives.
- Severity and status never by color alone. Tokens only; the `shell.css.test.ts` layout constants (1024, 864, 720, 1280) for container queries.
- Flakes: find the cause and make the test deterministic; never raise Playwright retries (CI retries once) or add sleeps. Waits target a state (`expect.poll`, `toHaveCSS`, `document.fonts.ready`, no pending source).
- Windows lane: `VITEST_MAX_WORKERS=3`; explicit `findBy` timeouts in admin tests (#610 pattern); e2e with `E2E_PORT=3200 pnpm e2e <spec> --project=chromium`; the full e2e suite before each push.
