## Global Constraints

- TypeScript strict; no `any`. `packages/core` pure. Every user-facing string is a message key (NFR-001); `en.json` plus the locale-keys test.
- Payloads and typed values are regulated data on the client (spec 6.7): memory only (no storage, no persister, no service worker); cleared on logout, 401 or user change; never in announcements, logs, analytics, accessible names or URLs. Announcements carry query type, short reference, counts, status words, severity and the configured keyword text only.
- Severity never by colour alone: icon (`aria-hidden`) plus text plus marker; `<mark>` plus marker for keyword hits (spec 4.5, 6.2).
- Focus: an incoming event, fetch or re-map never moves focus or remounts the focused row (stable keys: correlation ID, part, source); a card that expands or re-renders keeps the toggle's focus (spec 6.6).
- Announcer (spec 6.6): polite and coalesced per correlation ID within 1500 ms; `critical` severity assertive and never delayed by the window.
- Builder: payload content shows only inside the admin console; preview payloads come only from the draft's mock (fixture policy, design note); Try-a-match values live in component state only.
- Design: check UI against the mockup and the visual-system doc; dispatcher controls 36 px, officer targets 48 px or more (officer layout at 1024x768); focus ring outside the invalid edge.
- Docs: no em dashes; dates MM-DD-YY in prose.

### Task 3: `mapResponse`, path language and formats

**Files:** Create `packages/core/src/response/path.ts`, `format.ts`, `map.ts`, their tests and `map-response.a8.test.ts` (story A8 core half, tagged `[A8]`).
**Interfaces:** `mapResponse: MapResponse`; `resolvePath(payload, path): unknown[]` (dot segments, `[n]`, `["key.with.dots"]`, `[*]` projection); `formatValue(value, format?, locale)` (`text`, `upper`, `phone`, `date` with `pattern` key, `template` key; through `Intl` where spec 6.7 says so; dates MM-DD-YY by default). Selection (spec 4.5): candidates by `queryType` (required), `when` holds against `partValues` (spec 4.2 via the rules engine's condition evaluator, no new evaluator), `sourceId` and `persona` absent or equal; score `when` +4, `sourceId` +2, `persona` +1; ties to config order; no candidate yields the generic dump (every string, number and boolean leaf, label `{ text: path }`, `view: "both"`, payload order, highlight on).
