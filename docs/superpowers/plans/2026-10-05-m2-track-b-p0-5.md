## Global Constraints

- TypeScript strict; no `any`. Every user-facing string is a message key (NFR-001); `en.json` plus the locale-keys test.
- No field values, payloads or mock payload content in announcements, logs or analytics; the mock editor shows payload content only inside the admin console, to admins and implementers.
- Status text never colour alone; icons `aria-hidden`; an incoming event never moves focus or remounts the focused row (spec 6.6).
- Mock data follows the fixture policy (spec 5.4); scaffolded payloads carry no person, vehicle or address leaves.
- Design: check UI against the mockup and the visual-system doc; dispatcher controls 36 px, officer targets 48 px or more; focus ring outside the invalid edge.
- Docs: no em dashes; dates MM-DD-YY in prose.
