# apps/host-simulator

Planned for M4 P1 (Track B); not built yet. This folder holds only this README and `package.json`.

The plan (spec 6.9): a static host page for embedded-mode testing that signs demo JWTs, frames `/embed` and logs postMessage v1 traffic, so the embedding can be tested against a simulated CAD host page. It will never be bundled into the production image.
